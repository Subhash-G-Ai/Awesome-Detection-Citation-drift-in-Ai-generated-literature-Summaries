# Tools and Libraries

A minimal list of generative AI models and verification databases used for paper generation and citation auditing.

## Generative AI Tools

* **Gemini AI**: Primary generative AI model used to draft the initial research paper (Gemini 3.6 Flash)[cite: 1].
  * Link: https://gemini.google.com

* **ChatGPT**: Secondary generative AI tool used for brainstorming and prompt testing.
  * Link: https://chatgpt.com

## Reference Verification Tools

* **arXiv**: Open-access repository used to verify preprint identifiers, titles, and publication dates[cite: 1].
  * Link: https://arxiv.org

* **Crossref**: Official registry used to check persistent Digital Object Identifier (DOI) records and publication metadata[cite: 1].
  * Link: https://www.crossref.org
