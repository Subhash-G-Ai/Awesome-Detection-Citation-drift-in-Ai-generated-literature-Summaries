# AI Assistance and Verification Log

## 1. Project information

**Project:** Exact vs. Fuzzy Metadata Matching for Citation Record Recovery Under Controlled Corruption

**Purpose:** Document the use of AI assistance during research planning, implementation, analysis, and paper preparation.

## 2. AI-assisted research activities

| Stage | AI assistance | Human responsibility / verification |
|---|---|---|
| Literature review | Helped organize themes and identify possible research directions. | Researcher remained responsible for checking original papers and references. |
| Research gap | Helped compare candidate gaps and narrow the experimental scope. | Researcher selected the project direction and research questions. |
| Experimental design | Helped plan dataset use, baselines, metrics, and validation. | Researcher ran the experiment and determined which planned steps were actually implemented. |
| Coding | Helped explain and develop Python implementation components. | Researcher executed the code and reviewed actual outputs. |
| Debugging | Helped interpret reported errors and implementation questions. | Only actual execution results were treated as evidence. |
| Evaluation | Helped explain classification, retrieval, threshold sensitivity, and error analysis. | Reported metrics were taken from experiment outputs, not invented by AI. |
| Paper preparation | Helped organize and improve research writing. | Researcher remains responsible for the accuracy of methods, results, citations, and conclusions. |
| GitHub organization | Helped plan repository structure and documentation. | Researcher uploaded the project archive and experimental results. |
| Demonstration preparation | Helped prepare explanations and likely viva questions. | Researcher must understand and independently explain the implementation. |

## 3. Verification principles

The following principles were applied:

1. AI-generated references were not treated as evidence without independent checking.
2. Experimental metrics were based on saved outputs.
3. Code suggestions required execution and inspection.
4. Planned methods were distinguished from methods actually implemented.
5. Limitations and protocol deviations were retained rather than hidden.
6. AI was used as an assistant, not as an author or substitute for research judgment.

The researcher is responsible for:

- Understanding the research question and experimental methods.
- Confirming that the executed code matches the paper.
- Checking the source of reported results.
- Verifying bibliographic references.
- Explaining the limitations of the experiment.
- Ensuring the submitted repository can be inspected and reproduced.
